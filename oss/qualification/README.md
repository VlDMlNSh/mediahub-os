# Qualification evidence

One directory per component/version is required before activation.

Expected evidence:

- `provenance.json`
- `license.txt`
- `sbom.json`
- `vulnerability-report.json`
- `integration-report.md`
- `negative-tests.md`
- `degraded-recovery.md`
- `rollback.md`
- `independent-review.md`

Absence of required evidence keeps the component non-qualified.
