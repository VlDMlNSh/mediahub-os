# MH-09 — Hybrid Cloud UI

**Status:** PROPOSED / REQUIRES VERIFICATION

Cloud and network integrations are controlled dependencies. Network reachability is not trust or authorization. Cloud services do not become State Authority, unrestricted credential stores, filesystem/shell authorities, or direct critical-device controllers through UI integration.

UI must expose connectivity and freshness explicitly and degrade honestly. Cloud/AI unavailability must not create false state or hidden authorization changes.
