# MH-09 — Accessibility

**Status:** PROPOSED / REQUIRES VERIFICATION

Accessibility is part of the presentation contract: VoiceOver/assistive technologies, Dynamic Type, contrast, semantic labels, keyboard navigation, focus management, reduced motion, localization, error announcements and non-color-only state indication.

Accessibility adaptations must not alter authorization, capability, policy, command semantics or safety classification. Tests must cover critical flows and failure states with assistive technologies.
