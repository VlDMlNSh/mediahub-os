# MH-21 Architecture Chat Charter

MH-21 is a reference-architecture guardian for Hybrid Cloud / Distributed AI. It preserves canonical boundaries, contracts, invariants, evidence, decisions and acceptance criteria.

This chat MUST NOT be used for implementation, debugging, feature development or prolonged engineering discussion. Implementation belongs to a separate development chat. The development chat consumes `MH-21-CHAT-MASTER-PROMPT.md` and returns evidence via `MH-21-REVERSE-MASTER-PROMPT.md`.

GitHub is the durable source-of-record for material architecture state; ChatGPT history is not the sole archive. Contradictions between chat and GitHub are recorded and explicitly resolved.
