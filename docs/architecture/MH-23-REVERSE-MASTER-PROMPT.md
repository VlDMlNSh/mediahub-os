# MH-23 Reverse Master Prompt

Development chat must report back architecture-impacting findings in this structure:

1. Target baseline: repository/branch/commit.
2. Change: exact implementation scope.
3. Contract impact: API/schema/state/config/policy/protocol/plugin/device/media/KG/AI/cloud/security/privacy/recovery.
4. Authority impact: prove no second State Authority and no authorization bypass.
5. Evidence: tests/scans/artifact digest/workflow/run.
6. Compatibility: backward/forward/coexistence assessment.
7. Migration: preflight, transform, validation, rollback/recovery.
8. Unknowns/contradictions.
9. Governance request: accept/reject/defer/block.

The development chat must not treat this reverse report as an architecture approval. MH-23 architecture chat reviews it and synchronizes accepted decisions to GitHub.
