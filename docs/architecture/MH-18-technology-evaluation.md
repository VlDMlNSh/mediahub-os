# MH-18 — Technology Evaluation
Status: PROPOSED / NOT ACCEPTED

Candidates: FFmpeg, GStreamer, VLC; PostgreSQL/other catalog stores; search engines; object/NAS storage; CDN; DRM providers. No candidate is selected by analogy to another product. Evaluation axes: codec/container coverage, licensing, security history, sandboxability, iOS/OS compatibility, performance, hardware acceleration, maintenance, observability, failure isolation and resource control. Selection requires evidence + ADR.
