# MH-23 Architecture Invariants

1 State Authority is the sole canonical mutation authority. 2 External input, UI, AI, plugin, device, KG, digital twin, observability, persistence and cloud are not authority. 3 Policy Engine is not State Authority. 4 Network reachability ≠ authorization. 5 Discovery ≠ trust. 6 Presence ≠ authentication. 7 Event ≠ command. 8 Observation ≠ canonical state. 9 Prediction ≠ fact. 10 Backup ≠ HA. 11 Cache ≠ canonical state. 12 AI confidence ≠ authorization. 13 Security/privacy boundaries cannot weaken implicitly. 14 Critical operations require explicit authorization. 15 Ambiguity fails safely. 16 Destructive migration requires explicit gate. 17 Recovery remains independently trusted. 18 Production status requires evidence. 19 Architecturally significant technology requires evidence + ADR + authorization. 20 Frozen contracts cannot change silently.
