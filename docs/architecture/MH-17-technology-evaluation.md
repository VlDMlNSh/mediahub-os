# MH-17 — Technology Evaluation

**Status:** CANDIDATE / NOT SELECTED

Protocol and transport choices are evaluated against: identity and trust, security, capability discovery, command semantics, event/telemetry behavior, idempotency, lifecycle support, offline behavior, resource cost, platform availability, interoperability, licensing, maintenance, and testability.

MQTT, HTTP/REST, WebSocket, BLE, USB, serial, Zigbee, Z-Wave, Matter, HomeKit, ONVIF, mDNS, vendor APIs, and other technologies remain candidates unless separately supported by evidence, compatibility testing, security review, and an ADR.

Technology popularity or availability MUST NOT substitute for architectural authorization.
