# MH-18 — Content Security
Status: PROPOSED / NOT ACCEPTED

Threats: malicious media, parser/codec exploit, metadata injection, path traversal, archive bombs, oversized files, malformed codecs, hostile subtitles/artwork, poisoned AI input and unauthorized export/exfiltration. Defenses: bounded parsing, canonicalized locators, least privilege, isolation, quotas, validation, audit and fail-closed authorization.
