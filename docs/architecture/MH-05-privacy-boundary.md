# MH-5 — Privacy Boundary

**Status:** PROPOSED — GOVERNANCE REVIEW REQUIRED

Privacy follows local-first, data-minimization, and explicit-transfer principles.

Sensitive data access requires explicit authorization. Data leaving Core must have an explicit purpose, bounded representation, authorized destination/context, and observable correlation where appropriate. No implicit cloud export, hidden telemetry export, unrestricted RAG/document forwarding, or secret propagation is allowed.

External AI/cloud transfer is opt-in and policy-controlled. Consumer boundaries must not use errors, diagnostics, events, snapshots, or proposals as covert data-export channels.

Physical persistence remains unauthorized; durable personal-data protection therefore remains a future separately governed architecture concern.
