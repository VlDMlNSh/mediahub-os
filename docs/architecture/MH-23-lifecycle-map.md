# MH-23 Master Lifecycle Map

Feature: Proposed → Experimental → Candidate → Enabled → Stable → Deprecated → Maintenance → EOL → Removed.

System line: Baseline → Qualification → Release → Active → Maintenance → EOL → Decommissioned.

Migration: Prepare → Protect → Verify → Migrate → Validate → Health Gate → Observe → Promote; failure → Detect → Contain → Evidence → Recover/Rollback → Verify.

Governance status is independent of implementation status.
