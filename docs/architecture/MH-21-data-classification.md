# MH-21 Data Classification

Status: PROPOSED; taxonomy must align with MH-12/MH-13.

Minimum classes: PUBLIC, INTERNAL, SENSITIVE, PERSONAL, PRIVATE, SECURITY-SENSITIVE, SECRET, CRITICAL.

Each class must map to LOCAL_ONLY, LOCAL_PREFERRED, REMOTE_ALLOWED, REMOTE_ALLOWED_AFTER_REDACTION or REMOTE_PROHIBITED. No remote transfer decision may bypass classification.
