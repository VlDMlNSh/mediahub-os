# MH-18 — Privacy
Status: PROPOSED / NOT ACCEPTED

Media may contain faces, voices, locations, conversations, documents and behavioral information. Apply MH-13 principles: minimization, purpose limitation, access control, retention, redaction, explicit external transfer and audit.

Default: local processing where feasible; external transfer requires explicit authorized boundary. Logs must not contain payloads by default. Deletion/retention holds override convenience. Privacy review is required for new capture, AI or provider flows.
