# MH-09 — Offline-First Presentation

**Status:** PROPOSED

Local-first behavior is preferred where supported by the canonical contracts. Offline, degraded and reconnecting states are explicit presentation states.

Cached data must be identified as cached/stale and must never be represented as live canonical state. Loss of network, cloud, AI, optional plugin or external device must not manufacture success or authority.

Local drafts and presentation caches are not canonical persistence. No offline feature in MH-09 authorizes durable State Authority persistence; that remains a separate architectural decision.
