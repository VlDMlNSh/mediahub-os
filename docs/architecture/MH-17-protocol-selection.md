# MH-17 — Protocol Selection

**Status:** CANDIDATE / NOT SELECTED

Protocol selection is evidence-driven. A protocol/transport may be adopted only after evaluating identity/trust, authorization, capability semantics, commands, events, telemetry, idempotency, lifecycle, offline behavior, security, resource cost, compatibility, platform support, interoperability, and maintenance.

No protocol is privileged by popularity or ecosystem adoption. Selection requires an ADR and applicable security/compatibility evidence.
