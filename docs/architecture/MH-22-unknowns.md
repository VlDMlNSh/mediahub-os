# MH-22 — Unknowns Register

**Status:** ACTIVE

Critical unknowns currently include:

- current-HEAD full qualification result;
- immutable production release identity;
- artifact digest/signature/provenance;
- SBOM/dependency qualification;
- exact hardware qualification and sustained-load behavior;
- installation/update/rollback/recovery execution;
- backup restore and integrity/function validation;
- disaster-recovery exercise;
- production observability/SLI/SLO evidence;
- production acceptance approval.

Unknown is not PASS and must not be converted to PASS by absence of failures.
