# MH-12 Trust Model

Trust is explicit, contextual and revocable. Default trust is not inferred from locality, LAN presence, localhost, VPN, cloud, plugin installation, AI origin, device discovery, package signature, authentication or administrator status.

States: initial → enrollment → verification → active; degraded/suspended/revoked/quarantined are failure states.

Trust never replaces authorization and must be evaluated for the exact operation, target, scope and context.
