# MH-06 — AI Runtime Interaction

Status: PROPOSED

AI may analyze, diagnose, plan, recommend and produce inert proposals. AI is never runtime authority.

Canonical path: AI proposal -> validation -> inert request/data -> policy -> authorization -> command -> P0-05 -> P0-04.

No service may expose a proposal-to-execution shortcut, unrestricted shell/filesystem/network capability or autonomous security-policy mutation.
