# MH-09 — Privacy

**Status:** PROPOSED / REQUIRES VERIFICATION

Presentation follows least disclosure, data minimization, authorization-aware visibility and redaction. Sensitive values may require masking in screens, notifications, previews, screenshots and clipboard interactions.

UI caches/drafts/session data are not canonical persistence. Logging and telemetry must minimize sensitive content. A privacy restriction must never be treated as evidence that underlying state does not exist.
