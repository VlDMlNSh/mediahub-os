# MH-12 Network Security

Separate trusted local communication, untrusted local network, remote, internet/cloud, management, device and recovery planes.

Invariants: reachability ≠ trust; localhost ≠ trust; VPN ≠ authorization. Require explicit identity, authenticated transport where applicable, authorization, segmentation/isolation, ingress/egress controls, exposure minimization, rate/resource limits and audit.

Exact topology, addresses and ports require evidence.
