# MH-18 — Metadata
Status: PROPOSED / NOT ACCEPTED

Candidate fields: title, description, creator, artist, album, genre, year, language, duration, dimensions, bitrate, codec, chapters, subtitles, artwork, rating, tags, source, provenance and version.

Every material fact carries source, confidence where applicable, timestamp, provenance and schema/version. Metadata is descriptive data, not authorization or State Authority. Normalization must preserve source attribution and conflict evidence.
