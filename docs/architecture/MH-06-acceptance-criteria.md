# MH-06 — Acceptance Criteria

Status: PROPOSED

Acceptance requires: consistency with MH-1…MH-5; compatibility with P0-03…P0-07; unique mutation authority; explicit lifecycle; fail-closed behavior; bounded recovery; security invariants; no hidden persistence; no hidden network authority; no hidden AI authority; complete evidence register; contradiction disposition; unknown register; and traceable governance decision.

Verification must distinguish architecture acceptance from implementation quality and production qualification. No FROZEN or PRODUCTION READY claim is permitted without corresponding evidence and governance acceptance.

Implementation gate remains separate from this architecture document.
