# MH-19 Reverse Master Prompt — Development Feedback

Development chat must return to MH-19 only concise architecture-impact evidence:

1. implementation path/commit/PR;
2. contract or behavior changed;
3. evidence and tests actually executed;
4. affected MH-19 artifact;
5. contradiction or unknown introduced;
6. security/privacy impact;
7. proposed ADR if architecture changes;
8. explicit status: OBSERVED / VERIFIED / PROPOSED / UNKNOWN / REQUIRES VERIFICATION / BLOCKED.

Do not report implementation as ACCEPTED/FROZEN unless governance evidence exists. Architecture chat records decisions and evidence; implementation work belongs in development chats/repository implementation branches.
