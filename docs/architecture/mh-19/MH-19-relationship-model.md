# MH-19 Relationship Model
Status: PROPOSED

Candidate predicates: located_in, connected_to, controls, observes, contains, member_of, depends_on, powered_by, streams_to, derived_from, created_by, managed_by, compatible_with, replaces, related_to.

Every relationship requires semantics, provenance, validity, direction and cardinality; confidence applies where applicable. Existing CONNECTED_TO/CONTROLS/PART_OF/LOCATED_IN/USES/PROVIDES/DEPENDS_ON is foundation evidence. Relationship semantics never grant authorization.
