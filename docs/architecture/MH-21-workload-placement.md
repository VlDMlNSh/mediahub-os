# MH-21 Workload Placement

Status: PROPOSED.

Placement outcomes: LOCAL, REMOTE_TRUSTED, REMOTE_UNTRUSTED, PROVIDER_API, OFFLINE, BLOCKED.

Decision inputs: privacy, security, data sensitivity, task criticality, CPU/GPU/RAM, bandwidth, latency, cost, availability, model capability, reliability and regulatory constraints. Placement is policy-driven; cost or latency alone cannot authorize remote processing.
