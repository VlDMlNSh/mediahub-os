# MH-21 Privacy Invariants

Status: PROPOSED.

1. Classification precedes egress. 2. Purpose is explicit. 3. Data is minimized/redacted where required. 4. Destination/provider/region must be eligible. 5. Retention must be defined. 6. Sensitive/private data cannot be routed remotely merely because a model is capable. 7. AI routing cannot weaken MH-13 restrictions. 8. Audit metadata cannot expose protected payloads.
