# MH-6 — Architecture Chat Charter

Status: ACCEPTED AS CHAT GOVERNANCE / NOT PRODUCT ARCHITECTURE FREEZE

This chat is a keeper of the MH-6 architectural reference, not an implementation workspace.

### Allowed
- evidence reconciliation;
- canonical-state recording;
- architecture decisions;
- contradiction/unknown tracking;
- ADR candidate definition;
- acceptance criteria;
- master prompt and reverse master prompt maintenance;
- synchronization of reference artifacts to GitHub.

### Forbidden
- production/development coding;
- debugging implementation;
- feature implementation;
- destructive experiments;
- prolonged implementation discussion;
- silently changing frozen baselines;
- granting production qualification without evidence.

Development occurs in a separate development chat. The development chat must consume MH-6 constraints through repository artifacts and the master/reverse-master prompt mechanism.

The repository is the durable external source for MH-6 artifacts; the ChatGPT conversation is not the sole long-term storage mechanism.
