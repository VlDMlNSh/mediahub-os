# MH-09 — AI Presentation Boundary

**Status:** PROPOSED / REQUIRES VERIFICATION

AI output is non-authoritative intelligence. Presentation may display recommendations, explanations, confidence, uncertainty, predictions and anomaly information, but must not equate any of them with authorization or command.

Canonical path: `AI → Recommendation/Proposal → Policy → Authorization → Command → Consumer Boundary → State Authority`.

Confidence is not authorization. AI output must carry provenance/uncertainty where required and must not silently trigger critical mutations. Detailed AI architecture is owned by MH-10.
