# MH-12 Security Testing

Required evidence domains: unit/contract; authentication/authorization; capability; boundary; negative/malformed; escalation; forged identity/capability; replay; isolation; plugin; AI; cloud; update; recovery; supply chain; secret/dependency scanning; static/dynamic analysis; pentest/red-team where justified.

Mandatory negative property: missing permission must fail closed. Production qualification requires recorded verification evidence; architecture status alone does not qualify implementation.
