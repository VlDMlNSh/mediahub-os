# MH-12 Technology Evaluation

No technology is canonical without evidence + ADR. Candidates requiring evaluation include JWT/OAuth/OIDC, RBAC/ABAC/capability tokens, mTLS/PKI, secret stores, hardware-backed security, VPN/network controls, API gateways, IDS/IPS/SIEM and crypto libraries.

Evaluation criteria: security properties, compatibility with P0-03…P0-07 and MH-1…MH-11, cost, complexity, failure mode, trust implications, migration cost, evidence and governance status.
