# MH-04 Quarantine Model

Quarantine is containment, not authorization.

Triggers include unknown/suspicious principal or device, repeated authentication failures, policy/security boundary violation, or integrity uncertainty where defined by policy.

Quarantined subjects cannot mutate canonical state, self-release, self-elevate or bypass the integration/consumer boundary.

Exit requires an explicit verification/recovery path and renewed authorization. Repeated failure remains contained or is denied.
