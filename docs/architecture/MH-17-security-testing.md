# MH-17 — Security Testing

**Status:** PROPOSED / CANDIDATE

Security testing MUST cover discovery spoofing, identity collision, enrollment abuse, authentication failures, authorization bypass, capability escalation, malformed protocol data, replay, command injection, credential misuse, adapter isolation, plugin/AI/cloud boundary violations, quarantine, revocation, resource exhaustion, and sensitive-data leakage.

Tests must demonstrate default deny and absence of prohibited direct paths. Protocol-specific claims require evidence for the selected technology; no protocol is implicitly approved by this document.
