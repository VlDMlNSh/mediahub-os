# MH-11 Reverse Master Prompt

Return implementation/development findings to MH-11 using this contract.

## Required input
- repository and branch
- commit SHA(s)
- changed paths
- tests and exact results
- runtime evidence where applicable
- security/privacy scans
- capability/import/persistence findings
- observed contradictions
- unresolved unknowns

## Required classification
Every claim must be marked with a controlled status. Historical or chat-only claims without current evidence are REQUIRES VERIFICATION.

## Required conclusion
Report:
1. what was implemented;
2. what was tested;
3. what evidence proves it;
4. what remains unverified;
5. whether architecture is compatible with MH-11;
6. whether implementation authorization can proceed;
7. any contradiction requiring governance.

## Prohibited conclusion
Do not infer ACCEPTED/FROZEN/QUALIFIED from tests alone. Do not infer authority from telemetry or diagnostic access. Do not silently modify frozen P0-03…P0-06 foundations.
