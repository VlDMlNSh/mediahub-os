# MH-11 Unknown Register

Status: UNKNOWN / REQUIRES VERIFICATION

The following are intentionally not guessed:

- exact observability stack;
- exact logs/metrics/traces/event/audit schemas;
- retention periods;
- telemetry/audit/forensic storage;
- local storage limits and resource budgets;
- cloud observability topology;
- OpenTelemetry adoption;
- Prometheus/Grafana/Redis adoption;
- export format;
- privacy classification taxonomy;
- legal retention requirements;
- actual runtime instrumentation;
- exact diagnostic APIs;
- exact health/readiness implementation;
- current diagnostic UI implementation;
- trace propagation implementation;
- incident infrastructure.

Unknowns must be resolved only by evidence, ADR/governance decision, or explicit deferral.
