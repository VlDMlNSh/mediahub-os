# MH-17 — Testing Model

**Status:** CANDIDATE

Required layers:
- Unit: parsing, normalization, command construction.
- Contract: schemas, capability and lifecycle transitions.
- Integration: real/simulated devices and adapters.
- Security: spoofing, authentication, replay, malformed input, parser/resource abuse.
- Reliability: disconnect/reconnect, timeouts and device reboot.
- Chaos: loss, latency, duplication and reordering.
- Safety: critical actuator authorization and ambiguous outcomes.
- Privacy: minimization, access control and redaction.
- Compatibility: protocol/firmware versions.
- Recovery: replacement, revocation and re-enrollment.
