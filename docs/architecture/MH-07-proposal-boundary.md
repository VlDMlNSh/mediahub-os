# MH-7 — Proposal Boundary

Status: CANDIDATE

A proposal is an inert candidate representation. Proposal sources may recommend, validate, analyze, or identify conflicts, but cannot publish, mutate State Authority, self-authorize, alter capabilities, execute arbitrary code, or create persistence/network behavior.

Every proposal enters the same validation, policy and authorization path as other candidates before controlled publication. A proposal is never authoritative merely because it was generated by a trusted source.
