## 2. Security & Provenance Audit Findings

### A. Controller / Child Transport & HMAC
- **Mechanism:** Child workflows execute signed dispatch checks verifying HMAC-SHA256 signatures generated by the batch dispatch controller over canonicalized payload fields (`workflow_file`, `dispatch_id`, `target_sha`, `task`, `base_ref`, `scope`).
- **Validation:** `hmac.compare_digest` is used to prevent timing attacks. UUID shape validation (`[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}`) and 40-character target SHA constraints are enforced.
- **Fail-Closed Behavior:** Missing keys, invalid signatures, tampered payloads, incorrect workflow names, disallowed base refs/scopes, or incorrect event names/repositories cause immediate failure (`exit 1`).

### B. Issuer / Capability & Least Privilege
- **Permissions:** Review and engineering workflows strictly isolate permissions (`contents: read` or minimal required access), disable credential persistence (`persist-credentials: false`), and exclude unauthorized write scopes (e.g., no `pull-requests` permission on review jobs).
- **Product State Authority:** AI agents, cloud workflows, queues, and adapters do not possess Product State Authority. State mutation remains strictly gated.

### C. Secret Separation & Redaction
- **Enforcement:** `runtime/mediahub_runtime/astra_security.py` provides robust regex scanning (`scan_secret`), redaction (`redact`), and persistence validation (`require_safe`).
- **Evidence Governance:** Evidence metadata governance rules (`architecture/ASTRA-GOLD-GOVERNANCE-CONTRACT.yaml`) explicitly require secret values and authorization tokens to be `SUPPRESSED`, and raw provider responses to be `REDACTED`.

### D. Quota, Fallback Policy & Fail-Closed Behavior
- **Output Validators:** Step validators enforce that Gemini artifact outputs are non-empty, parseable JSON recording successful tool executions and Pull Request creation.
- **Error Handling:** Workflow steps use `if: always()` for outcome validation. Any non-success Gemini outcome or missing artifact fails the job closed without bypassing verification.
