their API/connectivity state. Authentication/authorization semantics, State Authority,
AI execution, transport topology and production release are explicitly out of scope.

## Acceptance evidence

- Platform values are bounded to `ios` and `ipados`.
- Connectivity values are bounded to `online`, `offline`, `degraded`.
- API compatibility exposes server/selected API versions only.
- Contract contains no credential, authorization, AI-tier or State Authority authority fields.
