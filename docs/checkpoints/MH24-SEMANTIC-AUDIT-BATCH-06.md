## 3. Cross-cutting findings

1. **Observability is non-authoritative.** Health reports observations; readiness is scoped to an operation. Neither grants trust, policy approval or command authority.
2. **Storage hierarchy must remain explicit.** PostgreSQL + pgvector + S3-compatible storage are the stated functional baseline; Qdrant remains conditional. Search/vector/graph/object stores are derived stores, not canonical state authorities.
3. **Knowledge is not truth by default.** AI-generated or retrieved knowledge needs provenance and source verification. Search results do not automatically become verified facts or canonical state.
4. **AI escalation is policy-bound.** Local → cluster → cloud is a routing pattern, not unconditional escalation. Privacy, data class, capability, user policy and egress authorization govern each task.
5. **OSS catalogue ≠ software bill of materials for a qualified release.** Component names and manifests do not prove adoption, installation, security status or production support.
6. **No silent duplicate authorities.** State, Smart Home, OTA, storage and AI authority boundaries must be enforced through contracts and negative-path evidence, not only prose.
7. **Qualification is an independent decision.** Self-review, autonomous-agent declarations, historical CI runs and architecture documents do not substitute for a traceable independent qualification result.
8. **R4 remains unresolved.** The previously recorded R4 commit SHA is not resolvable by GitHub API; the surviving tree SHA does not establish the missing commit's provenance. Do not claim R4 acceptance based on that reference.

## 4. Semantic disposition

- **Preserved / strongly represented:** observability as non-mutating, authority-first storage, source provenance and non-authoritative knowledge, policy-governed AI escalation, gap-led OSS adoption, no-competing-authority prohibitions, independent qualification gates.
- **Candidate gaps needing explicit evidence/decision:** retention and privacy contracts for telemetry; production storage topology and recovery; search evaluation and source-verification acceptance; live AI routing/egress enforcement; component-specific OSS adoption evidence; negative-path evidence for prohibited bypasses; current independently reviewed qualification result.
- **Unknown/not proven:** production telemetry stack, qualified persistence and recovery, search/knowledge quality, live escalation enforcement, installed/adopted component set, runtime absence of bypasses and any current GOLD/T5/F-03/release qualification pass.

Conclusions are scoped to the listed refs and inspected content. A missing path on one ref is not proof of global absence, and architecture text is not runtime evidence.
