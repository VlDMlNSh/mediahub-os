## Proposed contract and negative tests

Trusted admission must bind issuer identity, capability, policy digest/version, audience/repository/action, command/task/node, exact base/target SHA, allowed paths, expiry/revocation, nonce, and an atomic cancellable claim/lease receipt. Worker output is only an untrusted patch plus manifest and has no publication credential. A separate publisher revalidates the authority/claim, recomputes patch digest and size from actual bytes, checks exact path/mode semantics and current base, rejects traversal, symlinks, submodules, unexpected files and secret-bearing output, then publishes with its own short-lived least-privilege credential.

Negative fixtures must cover invalid issuer/signature; wrong audience/repository/action/identity/SHA; expiry/revocation/replay; policy digest mismatch; missing/expired/cancelled lease; patch digest/size mismatch; omitted/extra/unsafe paths; symlink/submodule/mode changes; stale base; artifact reuse; and publisher retry/idempotency. No production code or tests were run because accepted trust inputs and queue-claim semantics do not yet exist.
