# MH-02 — Trust Boundaries

PROPOSED trust model:
- T0 Trusted Core: State Authority / Core Runtime
- T1 Authorized Local Services
- T2 Presentation: UI/API
- T3 Integrations: devices/protocol adapters
- T4 Intelligence: AI/agents/RAG/KG
- T5 External Network: Internet/cloud/external APIs

Trust is explicit. Network reachability does not imply trust or authorization.
