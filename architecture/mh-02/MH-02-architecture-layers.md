# MH-02 — Architecture Layers

1. Presentation / Human Interfaces
2. AI / Intelligence / Automation
3. API / Capability / Command Boundary
4. Policy / Authorization / Security
5. Consumer / Integration Boundary
6. State Authority
7. Core Runtime / Lifecycle
8. OS / Hardware / Device Integration

Layer ordering is logical, not a blanket compile-time dependency rule. No upper layer may bypass authority/security boundaries.
