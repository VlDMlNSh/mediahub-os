# MH-02 — Control / Data / Management / Intelligence / Integration Planes

## Control Plane
Authorization, policy, lifecycle, orchestration, administration.

## Data Plane
Runtime state, events, telemetry, media/device data.

## Management Plane
Configuration, diagnostics, upgrades, recovery, observability.

## Intelligence Plane
Analytics, AI, recommendations, prediction, optimization.

## Integration Plane
Protocols, devices, external services, APIs.

Planes are distinct logical/security responsibilities. Management or intelligence operations that cause mutation must re-enter the normal authorization path.
